## Phase Goal

**As a** developer building an F1 prediction system, **I want to** run one command and see a real 2022 race's data land in a local SQLite database, **so that** I prove the FastF1 → normalize → ORM → SQLite stack works end-to-end before extending it to all seasons, weather, stints, and live polling.

<objective>
Establish the Walking Skeleton for Phase 1: install Phase 1's missing dependencies, scaffold the `f1_prediction` package, define the SQLAlchemy ORM base + WAL-mode engine + minimal raw schema (raw_sessions, raw_laps), wire a FastF1 loader that ingests one 2022 race, and prove the path works with a pytest end-to-end test.

This plan is intentionally narrow: one year, one round, two tables. Plans 02 and 03 widen this skeleton without changing its architectural decisions (engine config, ORM base, normalizer contract, package layout).

Output: A working `scripts/backfill.py --year 2022 --round 1` and a passing `tests/test_skeleton.py`.
</objective>
