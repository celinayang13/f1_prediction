<objective>
Extend the historical backfill to all 2022 rounds (17-22) and full 2023-2025 OpenF1 coverage, then fix the systemic `round_number=0` bug that blocks `championship_position` computation for OpenF1-sourced sessions. Re-run the feature builder so `features_prerace` and `features_inrace` have a complete training corpus before any model code is written.

This is Plan 01 of Phase 2 per D-01: training is gated on a complete data layer. The first vertical slice of "trained models on disk" is "a feature table with enough rows to train on."

Purpose: Without this plan, training rows are limited to 19 races (one 2023/2024/2025 race each) and `championship_position` is 100% NULL for 2023+. Both kill model signal.
Output: data/f1.db populated with ~85 race weekends of features; scripts/backfill.py augmented with the round_number fix; integration tests asserting row counts and non-zero round_number.
</objective>
