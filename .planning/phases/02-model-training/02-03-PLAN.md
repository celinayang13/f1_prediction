<objective>
Train and serialize the in-race XGBoost win-probability model. This is the second vertical slice of "trained model on disk" — it produces `data/models/inrace_model.joblib`, a calibrated classifier that consumes mid-race state features (position, gap to leader, tyre, pit stops, laps remaining) and outputs win probabilities that update lap-by-lap.

Per D-04, the in-race feature set is 10 columns including the categorical `tyre_compound`. Per RESEARCH.md Pattern 3, `tyre_compound` is one-hot encoded into 5 binary columns. Per D-08 and Plan 02, the same calibration + softmax pipeline is reused.

This plan reuses the `scripts/train.py` skeleton scaffolded in Plan 02-02 — it fills the `--model inrace` branch that Plan 02 stubbed with `NotImplementedError`, and adds in-race specific functions alongside the existing pre-race ones.

Purpose: Without a trained in-race model, Phase 3's inference loop cannot update probabilities lap-by-lap during a race. INRACE-01, INRACE-02, and INRACE-03 are all satisfied by this plan.
Output: scripts/train.py with --model inrace branch implemented, expanded tests/test_train.py, data/models/inrace_model.joblib.
</objective>
