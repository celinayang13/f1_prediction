<objective>
Validate that the trained pre-race and in-race model artifacts produce valid probability distributions on a held-out 2024 dataset. This is the final vertical slice of Phase 2: a runnable script that confirms the ROADMAP success criteria PRERACE-02 ("probabilities sum to 1.0 ± 0.001") and INRACE-02 ("updated win probability distribution per lap") hold for the saved artifacts.

Unlike the in-process sum-to-1 assertions in scripts/train.py (which run on the freshly-trained model), this script loads the persisted artifacts from disk, exercising the full Phase 3 integration contract: joblib.load → predict_proba → softmax → distribution. Any serialization or format regression is caught here before Phase 3 wires it into the FastAPI lifespan.

Purpose: Phase 3 inference will load these artifacts; this plan proves the artifacts are usable end-to-end. It also produces a metric report (Brier score + log loss) that informs future hyperparameter tuning decisions deferred to post-Phase 4.
Output: scripts/validate_model.py CLI; tests/test_validate_model.py unit tests; stdout JSON report.
</objective>

Accepts a 1-D probability array, a DataFrame containing the grouping columns (same length as raw_proba), the list of column names to group by (e.g., `["session_key"]` for prerace, `["session_key", "lap_number"]` for inrace), and a tolerance. Returns dict with keys `n_groups`, `min_sum`, `max_sum`, `violations` (list of group keys whose sum is outside tolerance). RAISES `AssertionError` with a message including the violating group keys if any are out of tolerance. Implementation:
       - `df = group_keys.copy(); df["raw_prob"] = raw_proba`
       - `df["win_prob"] = df.groupby(group_cols)["raw_prob"].transform(lambda x: softmax(x.values))`
       - `sums = df.groupby(group_cols)["win_prob"].sum()`
       - Delegate the assertion to the inner helper: `_assert_sums_within_tolerance(sums, tolerance)`
       - Return `{"n_groups": int(len(sums)), "min_sum": float(sums.min()), "max_sum": float(sums.max()), "violations": []}` on success.

    2. **MANDATORY HELPER:** `_assert_sums_within_tolerance(sums: pd.Series, tolerance: float) -> None` — A module-level helper (underscore-prefixed). Takes a pandas Series of per-group sums (Series index = group keys, values = computed sums) and a float tolerance. Computes `violations = sums[(sums - 1.0).abs() > tolerance]`. If `len(violations) > 0`, raises `AssertionError(f"Sum-to-1 violation for groups: {violations.index.tolist()} (sums: {violations.values.tolist()})")`. Otherwise returns None. **This helper MUST be a separately-defined module-level function (not nested inside validate_sum_to_one)** so that tests/test_validate_model.py can import and call it directly with manufactured `sums` Series to exercise the violation-detection path without going through softmax (which would make a violation mathematically impossible to construct). This extraction is REQUIRED — not optional.

    3. `validate_prerace_model(model_path: Path, val_year: int, tolerance: float) -> dict` — Loads the prerace model via joblib.load. Calls `load_prerace_training(get_engine(), max_year=val_year)`. Filters to year==val_year rows. Computes `raw_proba = model.predict_proba(val_df[PRERACE_FEATURE_COLS].values)[:, 1]`. Calls `validate_sum_to_one(raw_proba, val_df[["session_key"]], ["session_key"], tolerance)`. Computes Brier score and log loss on raw_proba vs val_df["is_winner"].values. Returns merged dict: `{"model": "prerace", "model_path": str(model_path), "val_year": val_year, "n_val_rows": int(len(val_df)), "brier_score": round(brier, 4), "log_loss": round(ll, 4), **sum_to_one_result}`.

    4. `validate_inrace_model(model_path: Path, val_year: int, tolerance: float) -> dict` — Loads the inrace model via joblib.load. Calls `load_inrace_training(get_engine(), max_year=val_year)`. Filters to year==val_year. Builds feature matrix via `X_val = build_inrace_feature_matrix(val_df).values`. Computes raw_proba. Calls `validate_sum_to_one(raw_proba, val_df[["session_key", "lap_number"]], ["session_key", "lap_number"], tolerance)`. Computes Brier + log loss. Returns merged dict with model="inrace" and additionally `n_val_lap_groups` from the sum-to-one result's n_groups.
