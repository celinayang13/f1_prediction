<objective>
Train and serialize the pre-race XGBoost win-probability model. This is the first end-to-end vertical slice of "trained model on disk" — it produces `data/models/prerace_model.joblib`, a calibrated classifier that consumes qualifying-and-practice features and outputs win probabilities that sum to 1.0 per race after softmax normalization.

Per D-09, this plan scaffolds the shared `scripts/train.py` script (used again by Plan 03 for the in-race branch). Per D-06, the model is XGBoost. Per D-08, calibration is `CalibratedClassifierCV` with isotonic regression. Per D-03, the feature set is exactly 7 columns.

Purpose: Without a trained pre-race model, Phase 3 cannot run any inference and the dashboard has no probability data to display. PRERACE-01, PRERACE-02, and PRERACE-03 are all satisfied by this plan.
Output: scripts/train.py (with --model prerace branch), tests/test_train.py (pre-race tests), data/models/prerace_model.joblib.
</objective>
